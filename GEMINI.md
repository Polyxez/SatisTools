# SatisTools Developer Guide

Внутриигровой мод для Satisfactory (v1.2).

## Правила и ограничения
- Следовать глобальным правилам `D:\gemini\agentsmain.md`.
- Минимизировать оверинжиниринг: простота, читаемость, надежность.
- Для карты: критически важна производительность отрисовки тысяч сплайнов и фабрик (кэширование, culling).

## Документация
- Архитектура карты: `docs/architecture/map.md`
- Требования: `REQUIREMENTS.md`

## Структура мода
- `SatisTools.uplugin`: конфигурация плагина Unreal Engine.
- `Source/`: исходный C++ код мода.
- `Content/`: UI (UMG/Slate), текстуры карты, стили.
