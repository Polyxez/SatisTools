# Архитектура модуля Карты (SatisTools Map)

## 1. Компоненты системы

```
UWorld
  ├── AFGBuildableSubsystem / AFGCircuitSubsystem
  └── World Actors (Nodes, DropPods, Vehicles, Players)
            │
            ▼
[ SatisToolsDataSubsystem ]
  • Сбор акторов мира при открытии / по таймеру
  • Индексация координат (Spatial Grid)
  • Извлечение данных: I/O рецептов, скорость конвейеров, чипы
            │
            ▼
[ SMapViewport (Slate Widget) ]
  • Преобразование координат (UE World ↔ Map Screen Space)
  • Frustum / Viewport Culling (отсечение объектов вне экрана)
  • Пакетная отрисовка конвейеров (FSlateDrawElement::MakeLines)
  • Отрисовка зданий, нод и маркеров (FSlateDrawElement::MakeBox)
            │
            ▼
[ UMapWidget (UMG Controller) ]
  • Управление вводом: Pan (drag), Zoom (wheel)
  • Панель фильтров слоев (Ресурсы, Заводы, Конвейеры, Транспорт)
  • Инструмент выделения (Lasso / Box Selection)
  • Инспектор зоны: расчет суммарного баланса I/O (items/min)
  • Сохранение и отображение пользовательских зон
```

## 2. Координатная система
Координаты мира Satisfactory (Unreal Units, 1 UU = 1 см):
- X диапазон: от -324 000 до 425 000 (~7490 м)
- Y диапазон: от -375 000 до 375 000 (~7500 м)
- Преобразование в нормализованные UV координаты карты:
  `U = (WorldX - MinX) / (MaxX - MinX)`
  `V = (WorldY - MinY) / (MaxY - MinY)`

## 3. Производительность и слои отрисовки (SCIM Fidelity)
- **Топография и террейн:** фоновые изолинии высот, кратерные озера с многослойными кольцами глубины.
- **Фундаменты (Foundations):** полупрозрачная модульная сетка плит 8×8 м (800 UU) под зданиями.
- **Логистика (Conveyors & Pipes):** конвейеры со стрелками направления и тирами скорости, трубы с индикаторами.
- **Железные дороги (Railways):** двухпутное полотно с балластом и петлями разворота.
- **Габариты станков:** точные размеры Конструкторов, Сборщиков и Изготовителей с портами подключения.
- **Бейджи объектов:** круглые маркеры с тенями для игрока, питомцев (Doggo), дисков и ящиков.
- **Batching & Culling:** пакетная отрисовка через Canvas/Slate без создания отдельных DOM/UMG виджетов.
